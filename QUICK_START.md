# ⏱️ 2-Minute Quick Start

## 1. Start the System
```bash
# Terminal 1: Backend
cd backend && python manage.py runserver

# Terminal 2: Frontend
cd frontend && npm install && npm run dev
```

## 2. Access the App
Open `http://localhost:5000` in your browser.

## 3. Test Credentials
- **Admin:** `admin` / `admin123456`
- **Employee:** `employee` / `test123456`
- **HR Manager:** `hr_manager` / `test123456`

## 4. Key Features to Demo
- **Executive View:** High-level metrics and the new functional **Export** button.
- **Reports Hub:** Fully rendering analytics charts and JSON export.
- **Role Switching:** Log out and log in with different roles to see tailored dashboards.
